# 🌸 Yume Note 夢 (Anime Notes for Android)

> **Персональное мобильное приложение заметок с аниме-интерфейсом и максимальной кастомизацией всего, что только можно.**

Разработано специально для Android-смартфонов как автономное PWA-приложение со 100% поддержкой офлайн-работы, тактильным виброоткликом (Haptics), синтезированными звуками интерфейса, динамическими частицами (Canvas FX) и интерактивным аниме-помощником.

---

## ✨ Основные возможности

### 🎨 1. Тотальная кастомизация «Всего, что только можно»
- **6 готовых проработанных аниме-стилей**:
  - 🌸 **Sakura Blossom** — Нежный романтичный стиль с лепестками сакуры и мягким пастельным свечением.
  - ⚡ **Cyberpunk Neon** — Высокотехнологичный неоновый стиль с косыми срезами карточек, желто-бирюзовыми акцентами и матричным дождем.
  - 🎭 **Persona Phantom** — Стильный дерзкий красно-черный контраст, диагональные плашки в духе Phantom Thieves.
  - 🔮 **Midnight Dark Magic** — Таинственный фиолетово-аметистовый стиль темного фэнтези и магических рун.
  - 🌊 **Blue Archive / Academy** — Свежий лазурно-голубой чистый хай-тек интерфейс.
  - 📼 **Retro 90s Manga** — Винтажный теплый стиль манги и аниме золотой эпохи 90-х.
- **Глубокий редактор тем (Custom Theme Builder)**:
  - Выбор любых собственных цветов через колорпикер (Основной акцент, Второй акцент, Фон приложения, Цвет карточек).
  - Слайдер радиуса скругления углов карточек (от строгих 0px до супер-скругленных 28px).
  - Слайдер эффекта размытия стекла (Glassmorphism Blur).
  - Настройка затемнения фона (Opacity).
  - Переключатель неонового свечения карточек.
  - Переключатель ретро CRT-сканлайнов (эффект экрана старого аниме-ТВ).
  - 5 вариантов шрифтов: *Anime Cursive, Sci-Fi Monospace, Pixel RPG, Kawaii Script, Clean System*.
  - Загрузка любых собственных обоев / картинок с вашего телефона в качестве фона!
  - Возможность переименовать само приложение в шапке (например, в «Заметки Артёма ✨» или «Death Note»).

### 🐾 2. Интерактивный аниме-маскот (Компаньон)
- 4 уникальных маскота на выбор:
  - 🐱 **Читосэ** — игривая кошкодевочка с милыми репликами и мурчанием.
  - ⚡ **Рэй** — киберпанк-нетраннер и страж зашифрованных данных.
  - 🔮 **Эмилия** — спокойная и мудрая кудере-волшебница архивов.
  - 🔥 **Кэн** — энергичный сёнэн-герой, мотивирующий на выполнение задач!
- Персонаж реагирует на время суток (утренние, дневные, вечерние и ночные реплики на японском и русском).
- Реакции на создание заметок, удаление, ввод пароля и тапы по экрану (с вылетающими сердечками и звуком).
- Возможность скрыть маскота в настройках.

### ✨ 3. Динамические спецэффекты (Canvas FX Engine)
- Легковесный движок частиц, работающий прямо на GPU без нагрузки на процессор:
  - 🌸 Падающие лепестки сакуры с реалистичным покачиванием.
  - 💻 Киберпанк-матрица (падающие иероглифы катаканы).
  - ✨ Магические искры и мерцающие звезды.
  - 💕 Взлетающие сердечки.
  - ❄️ Мягкий зимний снегопад.
  - 🚫 Режим энергосбережения (полное отключение частиц для экономии батареи).
- Слайдер настройки плотности частиц.

### 📝 4. Мощный функционал заметок
- **Форматы**: Обычный текст, Markdown с заголовками и форматированием, интерактивные To-Do чеклисты.
- **Интерактивные задачи**: Отмечайте чекбоксы прямо на карточке заметки с приятным звуком колокольчика!
- **Аниме-штампы статусов**: `[КВЕСТ]`, `[СЕКРЕТНО]`, `[ВАЖНО]`, `[ИДЕЯ]`, `[КАВАЙ]`.
- **Индивидуальный цвет**: Каждой заметке можно назначить свой уникальный оттенок карточки.
- **Закрепление**: Закрепляйте важные заметки наверху списка в один клик (📌).
- **Секретные заметки под PIN-кодом**:
  - Заметки надежно заблокированы PIN-кодом (по умолчанию `1234`, легко меняется в настройках).
  - Аниме-экран ввода пароля с защитой от подглядывания.
  - При ошибке маскот кричит: *«Бака! Неверный пароль!»*.
- **Холст для рисования (Doodle Pad)**:
  - Рисуйте заметки, схемы или автографы пальцем на экране смартфона!
  - Выбор цвета, толщины кисти, отмена шагов и прикрепление рисунка к заметке.
- **Экспорт в аниме-открытку (PNG)**:
  - Экспорт любой заметки в виде красивой стилизованной графической открытки для отправки друзьям в Telegram / VK.
- **Резервная копия**:
  - Полный экспорт и импорт базы заметок и настроек в JSON-файл.

### 🔊 5. Звуковой синтезатор UI (Web Audio API)
- Все звуки (клики, звоночки, аниме-поп, шелест удаления, фанфары) генерируются процедурно — никаких внешних тяжелых mp3 файлов, мгновенный отклик!
- Регулировка громкости и возможность беззвучного режима.
- Тактильный виброотклик (Haptic Feedback) на поддерживаемых смартфонах Android.

---

📱 Как установить на Android
🚀 Способ 1: Скачать готовый APK (Рекомендуемый, 10 секунд)

Скачайте файл YumeNote.apk (справа в блоке Releases или из файлов репозитория).
Нажмите на скачанный файл на вашем смартфоне и выберите «Установить».
Готово! Приложение появится на рабочем столе телефона и работает 100% автономно без интернета (полная поддержка Android 14+).

## 🔒 Безопасность и PIN-код

- Пароль по умолчанию для секретного раздела: **`1234`**
- Чтобы изменить PIN-код: перейдите во вкладку «Стиль» (Кастомизация) -> раздел «Защита и PIN-код» -> введите новый 4-значный код и нажмите «Обновить PIN-код».

## 🛠️ Стек технологий
- **HTML5 & CSS3**: Mobile-first responsive layout, CSS Custom Properties (Variables), Glassmorphism, CSS Grid & Flexbox, Safe Area Insets.
- **Vanilla ES6+ JavaScript**: Без тяжелых сторонних библиотек, молниеносный запуск за 50 мс.
- **Canvas 2D Context**: Физический движок частиц и холст для рисования заметок.
- **Web Audio API**: Процедурный синтезатор звуковых эффектов.
- **Service Worker & Web App Manifest**: Поддержка автономности и PWA на Android.
- **LocalStorage**: Мгновенное автосохранение всех заметок и параметров кастомизации.
